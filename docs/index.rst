smmargins
=========

Stata-style ``margins`` for `StatsModels
<https://www.statsmodels.org/>`_: adjusted predictions, marginal
effects, elasticities, and difference-in-differences with delta-method
standard errors — for any fitted model that exposes ``params``,
``cov_params()``, and ``predict(params, exog)``.
